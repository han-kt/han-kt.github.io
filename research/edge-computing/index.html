Research / Research area

Vehicular Edge Computing & Networking

Automated driving produces large, time-sensitive data flows, such as maps, shared perception, and model inference, that exceed what one vehicle can compute and what networks can deliver on demand. This work asks where computation should run, which data to send, and how to keep shared information fresh. It addresses these questions with methods that divide computation and data between vehicles and edge servers under latency and bandwidth limits.

Main themes

  1. Live HD maps from vehicle and edge collaboration

    Crowdsourced live high-definition maps built by collaborative computation between vehicles and edge servers, formulated to minimize transmission and computing resource usage under end-to-end latency limits; and COMAP, proactive provisioning of crowdsourced maps.

    Zhang et al., IEEE TVT 2024 · COMAP, IEEE ICC 2023

  2. Real-time cooperative perception at the edge

    AdaMap adaptively selects and compresses shared point-cloud data so that cooperative perception meets latency targets for large numbers of vehicles under changing network conditions.

    AdaMap, ACM/IEEE SEC 2023

  3. Learning-based data delivery and offloading

    DSORL, reinforcement-learning data-source selection for HD-map delivery in vehicular named data networking; REAL, learning-based offloading for edge-assisted mobile augmented reality; and network-aware task distribution for edge-assisted generative AI.

    DSORL, IEEE T-ITS 2023 · REAL, IEEE TMC 2026 · Yan et al., IEEE ICC 2026

  4. Vehicles as edge resources and information freshness

    CAVE, which crowdsources passing-by vehicles for reliable in-vehicle edge computing, and age-of-information-aware service aggregation for connected vehicles.

    CAVE, IEEE GLOBECOM 2024 · Mallik et al., IEEE ICC 2024

Systems and validation

  • Evaluation with an end-to-end 5G network simulator, a 5G emulation platform driven by a 150-vehicle CARLA trace, and a CARLA/ROS 2 vehicular named-data-networking environment. (Zhang et al., IEEE TVT 2024; AdaMap, ACM/IEEE SEC 2023; DSORL, IEEE T-ITS 2023)
